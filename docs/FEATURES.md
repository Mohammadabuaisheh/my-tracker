# Feature Inventory

## Fully Implemented
| Feature | Description | UI Location |
|---|---|---|
| **Kanban Board** | Column-based issue visualization by status. | Main `/` and Project Dashboard |
| **List View** | Compact list visualization of issues. | Main `/` and Project Dashboard |
| **Issue Creation** | Modal form to create issues with metadata. | Header/Sidebar 'New Issue' |
| **Project Creation** | Dialog to create new project spaces. | `/projects` |
| **Inline Renaming** | Edit project names directly without opening a form. | `/projects` Project Card |
| **View/Filter Sync** | Views and priority filters sync to URL params. | Board UI Controls |
| **Theming** | System, Dark, and Light mode toggling. | Sidebar/Settings |

## Not Implemented (Future Roadmap)
* Authentication / Private Workspaces
* Full-Text Search (FTS5)
* File Attachments
* Subtasks
